# Background jobs

Everything Aggregor runs that no command started: timers, polls, watchers, the processes it leaves running, and every
call that leaves the machine. Each window runs its own copy of the extension's jobs. Keep this table to what runs now:
add, change or delete a row in the same commit as the code.

Only `gh` reaches the network; every other job stays on the machine.

| Job                              | Interval                                           | Runs                                                                                                                                                                                                            | Checks or does                                                                                                                                                                     | Reaches                                           | Code                                                                                                                   |
| -------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Database change poll             | Scheduled: every 250 ms                            | `DATABASE_POLL_INTERVAL`, one per table (projects, sessions), untraced                                                                                                                                          | Reads `PRAGMA data_version`; when another connection wrote, reads the rows changed since the last read and publishes them to the services                                          | `aggregor.db`                                     | `BaseRepository.watchDataVersionChanges`, `BaseRepository.publishEntityChanges`                                        |
| Pull request lookups             | On event; focus refreshes at most once per 30 s    | When a session row is drawn and its branch isn't cached; again on window focus, at most every 30 s (`GITHUB_CLI.REFRESH_INTERVAL_MS`), for every branch looked up so far; forced when the setup terminal closes | `gh pr view` per branch, 4 at a time, each given up after 15 s                                                                                                                     | **GitHub, through `gh`**                          | `GitHubCliInfraService.runPullRequestLookups`, `GitHubCliInfraService.watchRefreshHints`                               |
| Pull request refresh on turn end | On event                                           | Each session write, untraced; a lookup only when an agent's turn ends                                                                                                                                           | Looks the session's pull request up again, since the agent may have pushed or opened one                                                                                           | **GitHub, through `gh`**                          | `PullRequestService.startPullRequestRefreshOnTurnEnd`                                                                  |
| Diff stats                       | On event                                           | Each time a session row in a worktree is drawn                                                                                                                                                                  | `git merge-base`, `git diff --numstat` and the new files' line counts against the base branch                                                                                      | The worktree                                      | `WorktreeInfraService.readDiffStats`                                                                                   |
| tmux check                       | On event                                           | On window focus and each closed terminal, untraced                                                                                                                                                              | Lists tmux's sessions to learn which agents still run; a tab whose tmux session ended closes                                                                                       | tmux server                                       | `TmuxInfraService.watchTmuxChangeHints`                                                                                |
| Session tab sync                 | Once at start                                      | When the window's extension starts, before the other jobs                                                                                                                                                       | Lists tmux's clients to learn which session each open session tab shows, since the shared tab outlives an extension restart on another session than it opened with                 | tmux server, terminals                            | `SessionService.syncSessionTabsWithTmux`                                                                               |
| Folder shell terminal sync       | Once at start                                      | When the window's extension starts                                                                                                                                                                              | Lists tmux's clients to learn which folder's shell the window's Aggregor terminal shows, since it outlives an extension restart on another folder's shell than it opened with      | tmux server, terminals                            | `FolderShellService.syncFolderShellTerminalWithTmux`                                                                   |
| Folder shell end on close        | On event                                           | Each closed terminal                                                                                                                                                                                            | When the user closed the Aggregor terminal, ends the shell it showed; a reload or a quit ends none                                                                                 | tmux server                                       | `FolderShellService.startFolderShellEndOnTerminalClose`, `TerminalInfraService.watchFolderShellPathsClosedByUser`      |
| Run state sync                   | On event; a stop settles for 10 s                  | Each change in the running agents; stopped ones settle for 10 s (`SESSION_RUN_STATE.STOP_SETTLE_INTERVAL`) first                                                                                                | Writes `runState`: `running`, cleared, or `interrupted` when the window starts with every agent gone                                                                               | `aggregor.db`                                     | `SessionService.startRunStateSync`                                                                                     |
| Session title and tab name sync  | On event                                           | Each session write (untraced), and each tab that comes to the front                                                                                                                                             | Saves the agent's title as `name` and renames the session's terminal tab                                                                                                           | `aggregor.db`, terminals                          | `SessionService.startSessionTitleSync`, `SessionService.startSessionTabNameSync`                                       |
| Viewed session                   | On event; settles for 100 ms                       | Each change of active terminal, tab, tab group or window focus, settled for 100 ms                                                                                                                              | Tracks the session in view, writes its `viewedAt`, and switches the workspace to its project                                                                                       | `aggregor.db`, workspace file                     | `TerminalInfraService.watchFocusChanges`, `SessionService.startViewedAtSync`, `WorkspaceService.startShownProjectSync` |
| Session alerts                   | On event; held for 3 s                             | Each session status change, held 3 s (`SESSION_ALERT_HOLD_MS`)                                                                                                                                                  | A session out of view that needs the user gets a VS Code notice or a desktop notification; `notify-send` (Linux) stays running until its notification closes, `osascript` on macOS | Desktop notifications                             | `SessionAlertService.watchSessionAlerts`, `SessionAlertsView`                                                          |
| Project settings sync            | On event                                           | Each `**/.vscode/settings.json` create, change or delete, each settings change, each workspace folder change                                                                                                    | Copies the shown project's settings into Aggregor's workspace file and back                                                                                                        | Workspace file, projects' `.vscode/settings.json` | `WorkspaceInfraService.watchProjectSettingsChanges`                                                                    |
| Setting watchers                 | On event                                           | Each settings change                                                                                                                                                                                            | Rereads the agents, trace logging, and the Sessions view's font size, accent colour and agent settings                                                                             | VS Code settings                                  | `AgentRepository.watchAgentSettings`, `TraceLog.watchTraceLoggingSetting`, `SessionsView.watchSettingChanges`          |
| Required tools check             | Once at start, then on event                       | When the window starts, and each time the setup terminal closes, while something is missing                                                                                                                     | Looks for tmux and gh on `PATH`, and offers to install what is missing                                                                                                             | `PATH`                                            | `RequiredToolsService.watchMissingTools`, `RequiredToolsNoticesView`                                                   |
| gh signed-out notice             | On event                                           | Each lookup that finds no `gh` account signed in, once until the next forced refresh                                                                                                                            | Offers **Sign In to GitHub CLI**                                                                                                                                                   | None                                              | `PullRequestService.watchGitHubCliSignedOut`, `GitHubCliNoticesView`                                                   |
| aggregor-pty                     | Always running; title written at most every 500 ms | One process per running session, inside tmux, for as long as its agent runs; outlives VS Code                                                                                                                   | Reads the agent's output for its status and title; writes status on each change, the title at most every 500 ms, and `exited` when the agent ends                                  | `aggregor.db`                                     | `apps/pty/src/main.rs`, `apps/pty/src/store.rs`                                                                        |
| Folder shells                    | Always running                                     | One tmux session per folder whose terminal was opened, holding the user's shell and what it started; outlives VS Code until `exit`, the panel's trash icon, or its worktree or project going                    | Runs what the user starts in a folder's terminal                                                                                                                                   | The folder                                        | `TmuxInfraService` (`folderShell.utils.ts`)                                                                            |
| tmux server                      | Always running                                     | One per Aggregor folder, started with the first session or folder shell; outlives VS Code until its last one ends                                                                                               | Keeps each agent, and each folder's shell, running when its terminal or window closes                                                                                              | None                                              | `TmuxInfraService`                                                                                                     |
